# MakeQR Chrome extension

1. Open `chrome://extensions` and switch on **Developer mode**.
2. Click **Load unpacked** and choose this `extension` folder.
3. Open any web page, click the extension, then **Open in MakeQR**.

The site opens in the studio with that page's link already filled in.
To use your own domain, edit `MAKEQR_URL` in `popup.js`.
